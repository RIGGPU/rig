## [0.1.0] - 2026-11-26

First release.

### Added

- Credits bought with USDG, ETH or $RIG on Robinhood Chain, refundable at the price paid
- Per-second GPU rentals with SSH and Jupyter, `rig/auto`, and one failover when a card does not start
- 13 media models priced per output
- API keys with daily spend caps and a stop switch
- MCP server with 14 tools
- x402 with EIP-3009 authorizations verified and settled by RIG
- Hourly Merkle roots of receipts written onchain, with proofs checked in the browser
- $RIG: free outputs for holders, hourly burn of used token credits
- Hand-written keccak-256, secp256k1, RLP, EIP-1559 and EIP-712
